### 2.2 Setup Verification Script
**Status**: Missing
**Impact**: Medium (helps troubleshooting)
**Effort**: Medium (20 minutes)

**Why**: Users can verify their setup is correct before running.

**Action**: Create `scripts/verify_setup.py`
```python
#!/usr/bin/env python3
"""
Verify local setup is correct before running the API.
"""
import os
import sys
from pathlib import Path

def check_env_vars():
    """Check required environment variables."""
    required = ["MISTRAL_API_KEY"]
    missing = [var for var in required if not os.getenv(var)]
    if missing:
        print(f"❌ Missing environment variables: {', '.join(missing)}")
        return False
    print("✅ Environment variables OK")
    return True

def check_data_files():
    """Check data files exist."""
    # Check for index or raw data
    index_path = Path("data/index/faiss_baseline/")
    if index_path.exists():
        print("✅ FAISS index found")
        return True

    raw_data = Path("data/processed/events_filtered.json")
    if raw_data.exists():
        print("✅ Processed data found (index will be built)")
        return True

    print("⚠️  No data found - will download on first run")
    return True

def check_dependencies():
    """Check Python dependencies."""
    try:
        import langchain
        import fastapi
        import faiss
        print("✅ Core dependencies installed")
        return True
    except ImportError as e:
        print(f"❌ Missing dependency: {e}")
        return False

if __name__ == "__main__":
    print("🔍 Verifying OC7-RAG setup...\n")

    checks = [
        check_env_vars(),
        check_dependencies(),
        check_data_files()
    ]

    if all(checks):
        print("\n✅ Setup verification complete! Ready to run.")
        sys.exit(0)
    else:
        print("\n❌ Setup verification failed. Fix issues above.")
        sys.exit(1)
```

## Category 6: Quality of Life Improvements 🛠️

### 6.1 Make Commands (Makefile)
**Status**: Missing
**Impact**: Medium (developer convenience)
**Effort**: Medium (20 minutes)

**Action**: Create `Makefile`
```makefile
.PHONY: help install test run docker-build docker-up clean

help:  ## Show this help message
	@grep -E '^[a-zA-Z_-]+:.*?## .*$$' $(MAKEFILE_LIST) | sort | awk 'BEGIN {FS = ":.*?## "}; {printf "\033[36m%-20s\033[0m %s\n", $$1, $$2}'

install:  ## Install dependencies
	pip install -r requirements.txt

test:  ## Run all tests
	pytest tests/ -v

test-fast:  ## Run fast tests only (no integration)
	pytest tests/ -v -m "not integration"

run:  ## Run API server locally
	python scripts/run_api.py

docker-build:  ## Build Docker image
	docker build -t oc7-rag-api .

docker-up:  ## Start Docker containers
	docker-compose up -d

docker-down:  ## Stop Docker containers
	docker-compose down

docker-logs:  ## View Docker logs
	docker-compose logs -f

verify:  ## Verify setup
	python scripts/verify_setup.py

clean:  ## Clean build artifacts
	find . -type d -name __pycache__ -exec rm -rf {} +
	find . -type f -name "*.pyc" -delete
```

Usage: `make help`, `make test`, `make docker-up`
